# Developer Guide, SDK & API Reference

This technical reference provides integration documentation for the AgriResolve TypeScript SDK (`@agriresolve/sdk`), the backend Indexer service (`indexer`), and Soroban RPC endpoints.

---

## SDK Installation & Configuration

Install the SDK in your TypeScript or JavaScript application:

```bash
npm install @agriresolve/sdk @stellar/stellar-sdk
# or with pnpm:
pnpm add @agriresolve/sdk @stellar/stellar-sdk
```

## SDK Client Reference

The package provides three primary client classes: `RegistryClient`, `EscrowClient`, and `DisputeClient`.

### 1. `EscrowClient`

Handles trade initialization, delivery confirmation, and split payout execution.

```typescript
import { EscrowClient } from "@agriresolve/sdk";
import { Keypair } from "@stellar/stellar-sdk";

const escrowClient = new EscrowClient();

// 1. Read trade details
const trade = await escrowClient.getTrade(1n);
console.log(`Trade #1 State: ${trade.state}, Amount: ${trade.amount}`);

// 2. Initialize a new trade escrow
const buyerKeypair = Keypair.fromSecret("S...");
const farmerAddress = "GDX712...";
const arbiterAddress = "GCBOKYT7TAARXDILFZ43QX2WWIRHAWA2S3V3ZP7EWN4KWTDIBS3NQS4Y";
const tokenAddress = "CCQGOTGN6HTQE74XYERYSYVU57T5NPYWV5DLCROMB56OXTV6RSO6KIGK";
const amount = 35000000000n; // $3,500.00 USDC
const expiry = BigInt(Math.floor(Date.now() / 1000) + 86400 * 7); // 7 days

const txHash = await escrowClient.initializeTrade(
  buyerKeypair,
  farmerAddress,
  arbiterAddress,
  tokenAddress,
  amount,
  expiry
);
console.log(`Trade initialized: tx ${txHash}`);

// 3. Confirm physical delivery
const farmerKeypair = Keypair.fromSecret("S...");
const deliveryTicketHash = "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855";

await escrowClient.confirmDelivery(farmerKeypair, 1n, deliveryTicketHash);
```

### 2. `RegistryClient`

Queries commodity moisture standards, participant profiles, and token whitelists.

```typescript
import { RegistryClient, ParticipantRole } from "@agriresolve/sdk";

const registryClient = new RegistryClient();

// Query commodity moisture parameters
const maizeSpec = await registryClient.getCommodity("MAIZE");
console.log(`Base moisture: ${maizeSpec.baseMoistureBps} bps (${maizeSpec.baseMoistureBps / 100}%)`);
console.log(`Max moisture: ${maizeSpec.maxMoistureBps} bps`);

// Query participant active status
const isActive = await registryClient.isParticipantActive("GCBOKYT7TAARXDILFZ43QX2WWIRHAWA2S3V3ZP7EWN4KWTDIBS3NQS4Y");
```

### 3. `DisputeClient`

Manages dispute dossiers, evidence attachments, and cross-contract resolution.

```typescript
import { DisputeClient } from "@agriresolve/sdk";
import { Keypair } from "@stellar/stellar-sdk";

const disputeClient = new DisputeClient();

// 1. Submit evidence hash
const buyerKeypair = Keypair.fromSecret("S...");
const evidenceHash = "8d4e9b6c1234567890abcdef1234567890abcdef1234567890abcdef12345678";

const evidenceIndex = await disputeClient.submitEvidence(
  buyerKeypair,
  1n, // disputeId
  "MOISTURE",
  evidenceHash
);

// 2. Resolve dispute (Oracle / Arbiter only)
const arbiterKeypair = Keypair.fromSecret("S...");
const resolutionHash = "a1b2c3d4...";

await disputeClient.resolveDispute(
  arbiterKeypair,
  1n,
  1592500000n,  // buyerShare ($159.25)
  33407500000n, // farmerShare ($3,340.75)
  resolutionHash
);
```

## Low-Level XDR Data Encoders

The SDK provides direct type conversion helpers between native TypeScript types and Soroban `xdr.ScVal`:

```typescript
import {
  addressToScVal,
  bytes32ToScVal,
  i128ToScVal,
  u64ToScVal,
  u32ToScVal,
  symbolToScVal,
  stringToScVal,
  boolToScVal,
  scValToNative,
  sha256Digest,
} from "@agriresolve/sdk";

// Convert 32-byte digest to ScVal BytesN<32>
const digest = sha256Digest("Weighbridge Gross Tare Ticket #WB-2026-9812");
const scBytes = bytes32ToScVal(digest);

// Decode ScVal back to native type
const nativeValue = scValToNative(scBytes);
```

## Event Poller Implementation

The indexer runs `SorobanEventPoller` to listen for on-chain contract emissions:

```typescript
import { rpc, scValToNative } from "@stellar/stellar-sdk";
import { TESTNET_CONFIG } from "@agriresolve/sdk";

const server = new rpc.Server(TESTNET_CONFIG.rpcUrl);

const res = await server.getEvents({
  startLedger: 1250000,
  filters: [
    {
      type: "contract",
      contractIds: [
        TESTNET_CONFIG.escrowContractId,
        TESTNET_CONFIG.disputeContractId,
      ],
    },
  ],
  limit: 50,
});
```
